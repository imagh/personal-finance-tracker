# Learnings digest

Standing rules and gotchas distilled from the learnings log; read this instead of the log. Each bullet ends with its source entry's date: `grep -n '^### <date>' docs/learnings/README.md` finds the detail.

## Testing: Robolectric and Compose
- Use `HostedComposeRule`, never `createComposeRule()` or `ui-test-manifest`: it registers `ComponentActivity` itself and runs on both debug and release unit-test variants [2026-10-29]
- One `setContent` per test. To vary input, hold state in `mutableStateOf`, write it with `runOnUiThread`, then `waitForIdle()`; loops over configs call the pure functions instead [2026-10-30]
- Mark any test that needs real glyphs, text measurement or `Paint.hasGlyph` with `@GraphicsMode(NATIVE)`; legacy mode measures text about 1px wide and `hasGlyph` is false for everything [2026-10-29, 2026-11-17]
- `captureToImage` times out (also for dialog and sheet windows). Check colours via pure mapping functions or `TextLayoutResult.layoutInput.style.color`; use `drawToBitmap` (inside `runOnUiThread`, after `waitForIdle`) for real draw-pass colours; use `drawSheetWindow` for sheets [2026-10-30, 2026-10-31, 2026-11-16]
- Assert fit with `isShownInFull()` (one line, `getLineEnd(0) == length`), never `hasVisualOverflow` (lies both ways); size hero tests with `Paise.MAX_AMOUNT` [2026-10-30]
- Put `testTag` after `graphicsLayer`/`offset` modifiers when a test reads geometry; step clocks with `advanceTimeByFrame()` plus `waitForIdle()` between frames; `advanceEventTime(300)` before `up()` to avoid fling [2026-10-29]
- Touch targets: assert `touchBoundsInRoot` (an `IconButton` is 40dp, target 48dp lives outside `boundsInRoot`) [2026-10-30]
- A merged `ListItem`/clickable row hides inner padding and clicks: assert geometry on `onNodeWithText(..., useUnmergedTree = true)`; `assertHasClickAction` fails on a `GroupedSection` row text though `performClick` works [2026-11-14]
- Assert log lines via `ShadowLog` filtered on `SafeLog.TAG`; the framework writes its own lines, so never assert that the unfiltered log is empty [2026-11-16]
- Robolectric qualifiers: Android order, `notnight` is the default so omit it; `+` only in a method-level `@Config`. For a method override use the whole string, e.g. `"w393dp-h900dp-notnight-xxhdpi"`, `"+h1500dp"` alone; `"+notnight+h…"` does not parse [2026-10-30, 2026-11-15, 2026-11-16]
- Give a test window enough height that the FAB does not cover a row and a row menu does not open at the window edge (Robolectric places the popup at negative coordinates); 1100-1400dp is used for category lists. Section rows are one lazy item, so `performScrollToNode` cannot reach inside [2026-11-15, 2026-11-16]
- Catalogue (debug) tests scroll with `performScrollToNode`; a new toggle row or page chip can push content below the 851dp fold. Under 560dp the header starts collapsed, so tests needing an expanded header set a taller window [2026-10-31, 2026-11-02]
- `performTextInput` on an unfocused field inserts at 0; use `performTextReplacement` for exact text. Keyboard type is testable: `LocalView.current.onCreateInputConnection(EditorInfo()).inputType`, with a `NameField` control [2026-11-02, 2026-11-15]
- ViewModels on `viewModelScope` (Main): wait with `awaitMain { compose.waitForIdle(); condition }`; `compose.waitUntil` alone is not enough. Never let a test throw an uncaught exception on a coroutine thread (it fails a later unrelated test) [2026-11-01, 2026-11-02]
- Press system Back via `Espresso.pressBack()` (also dismisses `ModalBottomSheet`), or capture the activity with `LocalContext.current as ComponentActivity` and call `onBackPressedDispatcher.onBackPressed()` [2026-11-02, 2026-11-16]
- Drive resume/pause with a hand-made `LifecycleRegistry` in `LocalLifecycleOwner`; test insets with `ViewCompat.dispatchApplyWindowInsets`; assert that a header does not recompose via `Recomposer.runningRecomposers.value.sumOf { it.changeCount }` [2026-10-29, 2026-10-31, 2026-11-14]
- Use `StateRestorationTester` from `androidx.compose.ui.test.junit4` for `rememberSaveable`; `compose::setContent` function references throw `NoClassDefFoundError`, use a local `val content: @Composable () -> Unit` [2026-11-17]
- Snackbar timers do not run in `waitForIdle`: `mainClock.advanceTimeBy(11_000)` for timeout; `SnackbarDuration.Indefinite` for position-only tests [2026-11-14]
- Dynamic colour under Robolectric is synthetic (`primaryContainer` tone 49/60): sweep it by grey tone, not M3 tones [2026-10-31]
- `ShadowLog`, `Locale`, ICU (`android.icu`) all work under Robolectric; M3 `Error` semantics is its own text, so assert field-in-error plus the displayed fixed message [2026-11-17]

## Test quality (prove tests bite)
- Every guard needs a test that fails when the guard is removed; run a mutation check and see red first. A happy-path outcome that is identical with and without the guard proves nothing (two rapid submits vs `saving`) [2026-11-02, 2026-11-16]
- Absence checks ("release has no X", "Setup not shown") need a positive control and must first wait for the screen to be shown; sampling only claims "not shown", not "never composed" [2026-11-02]
- A "do it again" guard test (second submit after saved) must use a different second input, or a core refusal (duplicate) hides a missing guard; mutate the guard to prove it [2026-11-17]
- Never write sleep-based "nothing happened" tests (`repeat(10) { idle(); Thread.sleep(10) }`); cancellation is pinned with `job.join()` and `job.isCancelled` in `LaunchSaveTest` [2026-11-16]
- Red phase for a new core class: compile-fail, then stubs with `TODO()` bodies so each test fails on `NotImplementedError` [2026-11-13]
- To test a tie-break or order dependence, write colliding rows through `AuditedWriter` with chosen ids and make the fake's order (newest first) disagree with the expected one; build "gap" cases (delete a sibling first) so a naive reorder differs [2026-11-14]
- "All or nothing" across services: fail an append that comes after real writes (the tenth, not the first); also assert one retry succeeds with no duplicates [2026-11-14]
- Refusal tests assert both "no row" and "no audit entry" [2026-11-13]
- A guard can be masked by the very next call: `require(size == 1)` followed by `single()` (which throws too) let the guard's mutation survive; return `first()` after a guard so only the guard refuses. Order tests need fixtures where store order, id order and the wanted order all disagree [2026-11-18]
- Build hostile or invisible characters from code points (`String(intArrayOf(cp), 0, 1)`); ktlint rewrites `"﻿"` literals and changes the test [2026-10-30]
- JUnit 4 `assertEquals` takes the message first, JUnit 5 last [2026-10-30]
- Tests that assert "the sans" name it (`sansFamily(SansFont.FIGTREE)`), not `FontFamily.Default`; negative-control a check that could pass vacuously (a tabular-figures check needs a no-`tnum` control) [2026-10-31]
- Pre-commit does not run `check`: run `./gradlew :core:<module>:check` before committing; keep each commit's code and tests together; JaCoCo coverage is on `core`, `requireTestsForProductionCode` closes fail-open [2026-10-29]
- An exact-equality guard (sum == amount) needs a fault in each direction: a store that drops a write and one that stores an extra, or `==` mutated to `>=` survives; inject it with a test-local `Repository by real` wrapper, not a wider kit [2026-11-18]
- Delete a bad test rather than keep an unfalsifiable guard (an `AtomicBoolean` "report once" guard no test could fail was removed as YAGNI) [2026-11-16]
- A read's order or cap guard needs rows that make the naive form differ: 1,003 rows at one instant (1,001 plain plus a pair) so only the group-id sort key keeps a pair inside the fetch; a filter naming **both** accounts of a transfer so only the id tie-break and the `foldTransfers` flag are observable; a category and a tag on different lines. A mutation script that replaces the first occurrence can hit a sibling query (two `ORDER BY at, id`): anchor on text unique to the target, and treat an unexpected survivor as a script bug first [2026-11-26]

## Compose UI, design system and accessibility
- Screens take background and cards from `PftTheme.surfaces` only; no `Color(0x…)` or font literals (a scanner fails on them); new money-carrying surfaces go into `ColorContrastTest` by value; never use light `surfaceContainerLowest` as a card, sheet or dialog fill [2026-10-30, 2026-10-31]
- Palette tests loop `ThemePalette.entries`; never rename or remove a `ThemePalette`, `SansFont` or `TypePairing` entry (persisted by name); keep persisted enums additive and have unknown stored values read as the default [2026-10-30, 2026-10-31]
- A pinned palette text colour (`onSurfaceVariant`) must clear 4.5:1 on every surface role and on the header glow, not just the canvas and island: choose the unpinned surface tones and the `wash` to fit the pins (Cobalt compresses its ladder and has a white light wash); brand tokens come from `PftTheme.brand`, derived by `derivedBrand` unless a palette picks its own, and app text is never `brand`; the island is never white except Cobalt light (D10) [2026-11-25]
- Fonts: reference every font as `R.font.<name>` from reachable code (R8 strips unreferenced ones silently); declare one `Font` per weight, each pinned one step heavier than its role weight (`shiftedSansWght`, capped at the axis maximum: 400 drawn at 500, 500 at 600, 600 at 700), with `FontVariation.Settings`; `FontBudgetTest` pins names and count (3 MiB budget for `res/font`); fetch only from the pinned google/fonts commit into an empty scratch dir; amounts need `tnum` (Figtree, Plus Jakarta and Bricolage default digits are proportional; Newsreader and Manrope are already tabular, so their negative control is `pnum`, not a missing `tnum`); `Paint.hasGlyph` under Robolectric native graphics also uses system fallback fonts and says true for a CJK character, so prove a bundled font's `cmap` and `GSUB` coverage from its bytes (`FontFileFacts`); a variable font's own axis defaults are its heaviest or lightest instance (Bricolage `wght` 800, Manrope 200), so pin every axis [2026-10-30, 2026-10-31, 2026-11-25, 2026-11-26]
- Header rule: serif (Newsreader) only for the dashboard hero number; titles sans, read-only, high; hero, caption and period stepper low (thumb zone); add actions go in the FAB, never the header; header actions use `HeaderIconButton` [2026-10-29, 2026-10-30]
- Money display: UI never reformats money; `PaiseFormat.format` has no sign, the caller adds U+2212 or `+`; every amount carries a sign or word, not only colour; `MoneyText` throws for a negative with a non-`Balance` semantic, so pass magnitudes. Never clip a money figure with `maxLines` as its only fit strategy (hero shrinks 48 to 12sp, then wraps) [2026-10-29, 2026-10-30]
- Colour meaning: an expense is neutral at every size (row, total, hero), a signed `Net` is always neutral, income is green; red is only a negative balance and an over-budget figure, amber a budget at its threshold; `MoneyText(onColor)` is neutral tones only (it throws otherwise) and `fadeDecimals` fades only while the hero is >= 24sp; no network font or emoji downloads [2026-10-29, 2026-11-25]
- A badge beside a title that already says the name must be silent: `RowGlyph.label` / `CategoryGlyph(name = null)` clears semantics. Cells with visible text speak that text; text-less cells (`SymbolGrid`, `ColourSwatches`) carry the spoken name and the inner badge is decorative. Emoji cells get no `contentDescription` (TalkBack reads the Unicode name) [2026-11-15, 2026-11-16, 2026-11-17]
- A list row that must speak as one node uses `clearAndSetSemantics` with one description: a merging parent does not fold in children that merge their own descendants (`MoneyText`, `StatusChip`). An island `Surface` gives no content colour: set `onSurface` explicitly. Compose pads touch bounds to 48dp, so assert drawn height, not bounds. `Row`-size money cannot hold `MAX_AMOUNT` on one line at 200%: stack it and assert never-cut [2026-11-25]
- `clearAndSetSemantics` on a clickable keeps its role/action; set `Role.Image` only when not clickable. Check "no Image role" assertions: Back and overflow buttons are images [2026-10-30, 2026-11-15]
- A form-level message is a polite live region (`LiveRegionMode.Polite`) coloured `colorScheme.error`; shared blocks hard-code no user-facing text (`form_save`, `form_back` strings) [2026-11-02, 2026-11-02]
- M3 `Scaffold` pads the list by bottom insets only when `bottomBar` emits no placeables: keep `bottomBar` nullable. `FlowRow` is still experimental in the BOM: use `TileGrid` (Column of Rows over `BoxWithConstraints`). Wrap very short segmented labels: row `height(IntrinsicSize.Min)`, `fillMaxHeight()` per button, `icon = {}` [2026-10-29, 2026-11-15, 2026-11-16]

- Pickers build on `TileGrid`, `selectionRing` and `PftBottomSheet` (content gets a `close` lambda, the only way to dismiss); a picker guards its own double tap with a `picked` flag; a bottom sheet title is a heading [2026-11-16]

## Forms and save shape
- A ViewModel save uses `launchSave` (`ui/common`, a `CoroutineScope` extension) with `SaveOutcome { SAVED, VANISHED, FAILED }`; pass `refused: (LedgerError) -> Boolean` for field-level answers like `DuplicateName`. `SetupViewModel` stays concrete [2026-11-16]
- Save shape: catch order `AlreadyInitialised`/specific, then rethrow `CancellationException`, then `catch (_: Exception)` (the `_` name satisfies detekt `TooGenericExceptionCaught`/`SwallowedException`; comment why); reset `saving`, show a fixed message, emit a field-less `LogEvent`, keep the typed text; never show or log the exception [2026-11-02]
- Write a save as an outcome value read by one `when`, not early returns; `FieldState.check(rule)` returns `FieldCheck(value, state)`; a non-field `LedgerError` is rethrown, not swallowed [2026-11-02, 2026-11-15]
- `toFieldError()` is an exhaustive `when` with no `else`: a new `LedgerError` and its `FieldError` + string land in the same commit [2026-11-02, 2026-11-13]
- A blank amount is `Required` (type `0` for none); an untouched balance is saved as stored (the form shows magnitudes only, so editing a name must not flip an overdrawn account) [2026-11-15]
- `AmountField` strips the leading `₹` on prefill and draws it as a prefix; `PaiseParser` also accepts a typed `₹` [2026-11-15]
- Stale-screen results ("no longer exists") cross a pop through the previous entry's `savedStateHandle`; reset the flag only after `showSnackbar` returns, and test it with the clock advanced [2026-11-15]
- A form draws nothing until loaded: flow tests wait for a field before asserting. A route with 6+ parameters takes a request object (`CategoryEditRequest`); untrusted nav arguments are validated in the ViewModel [2026-11-16]

## Data, Room and migrations
- Build every database with `PftDatabase.create(...)` (attaches trigger callback and migrations; triggers reinstalled on every open); never `Room.databaseBuilder` directly [2026-10-30]
- New entity: copy `RoomEntityRepository` + `MetaColumns`; `@Entity(primaryKeys = ["id"])` (Room ignores an `@PrimaryKey` inside `@Embedded`); add to `AuditedTables`; register in `Migrations.ALL`; bump `PftDatabase.VERSION`; add it to `SampleDatabase` or KSP fails; write `migrateNToN+1` in `src/testDebug` with `MigrationTestSupport` (it must check audit triggers survived) [2026-10-30, 2026-11-14]
- Copy migration SQL from the exported `N.json`, never from memory; Room writes `@Embedded` columns last, so compare column sets; the first run after a version bump fails with "Cannot find the schema file": rerun; add the trailing newline to the new JSON [2026-11-14]
- After reverting an entity mutation run `./gradlew :app:kspDebugKotlin --rerun` and diff the schema JSON (build cache leaves it stale) [2026-11-14]
- Room cannot declare CHECK constraints and entities have no partial indexes: rules live in core and the mapper; mappers fail closed on an unknown stored `kind`/`system_key`/`type` (message names the column, never the value) but fall back for `colour`/`icon_key` [2026-11-14]
- SQLite enforces foreign keys on both engines: insert parents before children in any copy/rebuild/test seed; self-reference needs `ForeignKey` plus an `Index` on the child column [2026-11-14]
- Every schema-version PR runs `EncryptedMigrationTest` and `EncryptedDatabaseTest` together on the `pft35` emulator (`-Pandroid.testInstrumentationRunnerArguments.class=<fqcn>,<fqcn>`); they must fail with "A migration from 1 to N was required but not found" if the migration is removed. `room-testing` is not on the androidTest lock (owner has not decided); the test replays `1.json` from test assets [2026-11-14]
- Open the encrypted DB through `DatabaseFactory` only; never hand SQLCipher the array from `DbKeyManager.useKey` (zero-filled; keys every connection). Re-run `EncryptedDatabaseTest` when bumping sqlcipher-android and read its bundled SQLite from the `.so` [2026-10-30]
- `PreMigrationBackup` copies `-wal` too; in write-A-then-B sequences delete A with non-throwing calls when B fails, and make cleanup treat "A without B" as garbage [2026-10-30, 2026-11-10]
- Times are stored as exact epoch ms: `EpochMillis.of` refuses a finer instant; core's `Clock` is `EpochMillis.clock()` [2026-10-30]
- Settings keys match `SettingsService.KEY_PATTERN` (`[a-z][a-z0-9_]*`), e.g. `ui_theme_mode`, not dotted [2026-10-30]
- `AppContainer.open()` is the only entry (M1b's receiver calls it, never `DatabaseStartup.open`); open is a cached `Deferred` on a container-owned scope; keep blocking work off Main via an injected dispatcher; the open takes ~75 ms/connection key, so never on Main. M1b must handle credential-encrypted storage before first unlock and consider retrying `KeyUnavailable` only [2026-11-01, 2026-10-30]
- App ID `dev.imagh.pft` and the release signing key are permanent: build and verify encrypted full export/import before changing either [2026-10-28]
- C1 onwards: schema versions are C1 v5, C3 v6, D3 v7, E3 v8, F2 v9, G1 v10 (tag took v4); the plans' `CHECK (amount > 0)`/`CHECK (position > 0)` on transaction tables are enforced in core and mappers, never in the schema [2026-11-17]
- An audited value held in a join table (a line's `tag_ids`) has no column: register it with `AuditedTable(keysStoredIn = mapOf(key to table))`; `AuditColumnsCheck` accepts it only if that table exists and is in `AuditedTables.notEntityTables` and the sample audits the key. A repository that writes a row and its join rows wraps both in `runner.inTransaction` (it nests), and a test calls it outside any service transaction; a cross-row invariant ("lines sum to the amount") cannot be a trigger or `CHECK`, so core checks it and a count query (`breakdownMismatchCount`) shows a violation [2026-11-18]
- FTS4 external content joins on the content table's implicit `rowid`; with TEXT ids it is not an alias and `VACUUM`/`VACUUM INTO` may renumber it, so an external-content index needs a `rebuild` rule and its shadow tables registered in the audit-columns test (slice C plan D6) [2026-11-18]
- FTS4 search (C3b): the prefix star goes **inside** the quotes (`"word*"`; `"word"*` is an exact word) and a column-qualified phrase (`title:"w*"`) matches nothing, so restrict with `col MATCH ?` and keep `:` out of typed text (an in-query `col:` overrides the restriction); a malformed `MATCH` throws, so typed text only reaches it through `SearchText.toMatchTerms` (one quoted `"w*"` term per word, **one bound `MATCH` per word**, ANDed in SQL); a non-null text with no word matches **nothing** (null is the only "no filter"); `unicode61` treats combining marks as separators (Devanagari "किराना" splits into क, र, न), so both tables declare the Devanagari marks as `tokenchars=` and other Indic scripts need the same plus a drop/recreate/`rebuild` migration; a tombstone is an `UPDATE`, so filter `deleted_at` on the content tables; Room drops its sync triggers in `onPreMigrate` and recreates them in `onPostMigrate`, so a migration that writes a content table ends with the two `rebuild` statements; tests that list every trigger expect the eight `room_fts_content_sync_*` ones too (`AuditedTables.ftsSyncTriggers`); check an FTS delete against the index alone (a join to the content table cannot fail); run `TransactionFts.REBUILD` after `VACUUM`/`VACUUM INTO`/export; SQLCipher 4.7.2 bundles SQLite 3.49.1 [2026-11-27]
- Filtered reads (slice C D5): a query with optional filters and list-valued `IN` sets is a `@RawQuery` over a `SimpleSQLiteQuery` whose text holds fixed fragments and `?` only (the placeholder *count* comes from a set's size, never a value); detekt `LongParameterList` (6) makes a fixed `@Query` with a dozen parameters impossible. Lines and tag rows are read by joining to the same matching sub-query (same predicate, order, `LIMIT`), never an `IN (:ids)` list; run each read in one `runner.inTransaction` for a snapshot. Read-side ordering needs a total order (`occurred_at DESC, COALESCE(transfer_group_id, id), id`) and a cap counted in **entries after folding**, fetching `SearchPage.FETCH_ROWS = 2 * (cap + 1)` rows so a pair is never cut [2026-11-26]
- A user-chosen sort is a **constant `ORDER BY` fragment picked by an exhaustive `when` over the enum key and direction**, then the fixed tie-breaks (ascending in both directions); no caller value is in the SQL text, and the lines/tags sub-queries take the same order. Check what each key shares between a transfer's two legs: `occurred_at`, `amount` and `title` come from one draft, but `created_at`/`updated_at` are two clock reads, so those two keys rank a pair by one value for both legs and **both directions** (`CREATED` by the group's `MIN`, `UPDATED` by its `MAX`; a different aggregate per direction breaks asc = reverse of desc, since an edit of one side moves one leg's `updated_at` by days) or the legs can be cut apart at the fetch edge. SQLite `NOCASE` folds ASCII only [2026-11-27]
